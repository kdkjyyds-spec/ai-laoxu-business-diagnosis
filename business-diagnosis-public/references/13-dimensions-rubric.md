# 13 维度评分规则

> 用于 13 维度自动评分 + 关键证据提取。每个维度 1-5 星。

---

## 维度定义

### 底座 3 维度（用户原话必含）

| 维度 | 评估什么 | 评分锚点 |
|------|----------|----------|
| 1. 可行度 | 这个项目能不能跑通 | 时薪 ≥500=5；200-500=4；100-200=3；50-100=2；<50=1 |
| 2. 商业模式难易 | 商业逻辑好不好做 | 平台/SaaS=5；内容/IP=4；咨询/培训=3；零售=3；纯销售=3 |
| 3. 资源依赖 | 启动需要多少资源 | 0 成本=5；<1 千=4；1-5 千=3；>5 千=2 |

### 补充 10 维度（精选）

| 维度 | 评估什么 | 评分锚点 |
|------|----------|----------|
| A1 商业逻辑 | 模式自洽 | 模式完整自洽=5；基本=3；矛盾=1 |
| A2 真实需求 | 是真痛点还是伪痛点 | 有数据+有场景=5；定性=3；模糊=1 |
| A3 客单价 | 跟市场对比 | 行业 1-3 倍合理=4；偏低=3；过高=2 |
| A5 数据可靠 | 财务算得清 | 4 要素齐全=4；缺 1=3；缺 2=2；全缺=1 |
| B1 启动资金 | 0 元能启动 | 0=5；<1 千=4；1-5 千=3；>1 万=2 |
| B3 能力匹配 | 跟作者背景是否匹配 | 完美匹配+有案例=5；部分=3；不匹配=1 |
| C1 风险敞口 | 失败损失多少 | 投入<5h 失败损失小=5；>20h=2 |
| C2 现金流 | 收钱节点 | 预付+尾款=5；验收付=3；后付=2 |
| D1 复购 | 客户会不会再来 | 订阅制=5；套餐=4；一次性=1 |
| D2 可复制 | 0→1 后能不能 1→100 | SOP 化=5；单点=2 |

## 自动评分规则

### 1. 可行度
```
if hourly is not None:
    if hourly >= 500: 5
    elif hourly >= 200: 4
    elif hourly >= 100: 3
    elif hourly >= 50: 2
    else: 1
elif profit is not None:
    if profit >= 10000: 4
    elif profit >= 5000: 3
    elif profit >= 3000: 2
    else: 1
else: 1
```

### 2. 商业模式难易
```
if '平台' or 'SaaS' or 'App' or '小程序' in project: 5
elif '社群' or 'IP' or '短视频' or '直播' or '内容' in project: 4
elif '咨询' or '陪跑' or '培训' or '辅导' or '课程' in project: 3
elif '卖' or '销售' or '零售' or '食品' in project: 3
else: 3
```

### 3. 资源依赖
```
if cost == 0: 5
elif cost and cost <= 1000: 4
elif cost and cost <= 5000: 3
else: 2
```

### A5 数据可靠
```
data_complete = sum([1 if income, 1 if cost, 1 if profit, 1 if hourly])
return data_complete  # 0-4
```

### B1 启动资金
```
if cost == 0: 5
elif cost and cost <= 1000: 4
else: 3
```

### 其他维度
- A1 / A2 / A3 / B3 / C1 / C2 / D1 / D2：基于原文关键词匹配 + AI 评估
- 关键词库见各章节

## 关键证据提取

每个维度评分时，**必须附 1-2 句关键证据**（从原文中摘录）。

提取规则：
1. 优先匹配关键词
2. 取 1-2 句最相关的（30-200 字）
3. 如果没找到，标"未明确涉及"

关键词库示例：
- A1 商业逻辑：`商业模式`, `客单价`, `盈利`, `收费`
- A2 真实需求：`市场需求`, `痛点`, `机会`, `客户群`
- C2 现金流：`预付`, `尾款`, `首付款`, `收钱`
- D1 复购：`复购`, `转介绍`, `老客户`, `裂变`
- D2 可复制：`复制`, `规模化`, `连锁`, `SOP`
