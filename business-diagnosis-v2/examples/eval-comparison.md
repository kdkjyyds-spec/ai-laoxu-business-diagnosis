# Eval 对比报告：baseline vs with-skill

> **测试项目**：AI 辅助中医出海平台（中医师 5 年三甲 + AI 工具 + 在线课程 + 保健品）
> **测试时间**：2026-08-07
> **测试目的**：验证 business-diagnosis skill 是否能带来增量价值

---

| 维度 | baseline（无 skill）| with-skill-v2 | 差距 |

| 行数 | 100 | 282 | 2.8 倍 |

## 二、核心差异

### 差异 1：方法论结构

**baseline** 自创 8 维度（商业可行性/模式健康度/创始人匹配度/同类对比优势/创新性/长期价值/风险与脆弱性/目标可达性）

**with-skill-v2** 用 skill 内置 6 层：
- 本体画布（BMC 9 要素）
- 可行性（市场/财务/法律/技术/团队/资本 6 维）
- 健康度（增长/复购/复制/抗风险/客户/效率/财务 7 维）
- 对比（直接竞品/替代品/跨界/标杆/护城河）
- 创新（价值/收入/成本/渠道/关系/复制/杠杆 7 方向）
- 长期价值（市场/窗口/周期/沉淀/复制/退出/匹配 7 维）

✅ **结论**：with-skill 结构更系统，覆盖面更全（基线漏了"渠道通路""重要伙伴""成本结构"等 BMC 9 要素）

### 差异 2：知识库引用（最关键差异）

| 类型 | baseline | with-skill-v2 |
|------|----------|---------------|
| 引用 sample-library 案例 | 0 | **15 个** |
| 引用 industry-patterns | 0 | 3 个（中医出海 4 种模式）|
| 引用 24 主题陷阱表 | 0 | 2 个（健康/美业合规 + AI 工具 3 月失效）|
| 引用共性短板清单 | 0 | 1 个（剧本式风控缺失）|

✅ **结论**：with-skill 把 1718 份立项 + 1-9 期实战的 200+ 案例变成了"诊断的对照锚点"，baseline 完全没有这个能力

### 差异 3：横向对比深度

**baseline**：泛泛对比"传统海外中医诊所""纯 AI 中医 APP""中医保健品电商"，没有具体案例名

**with-skill-v2**：4 个具体标杆详细对比
- 主题 6 青少年心理（综合得分 4.46 TOP 1）—— 客单价对标 + 剧本式风控借鉴
- 主题 2 商业工具包（综合得分 4.08 TOP 2）—— 4 级价格漏斗借鉴
- 主题 18 英文工具站 + YouTube —— 出海获客渠道对标
- 主题 5 Pathfinder AI —— AI + 行业 know-how 模式对标

每个对比都包含：客单价对比 + 时薪对比 + 关键设计对比 + 适用场景对比 + "学什么"清单

✅ **结论**：with-skill 把"对比"从"泛泛对比"升级为"精确到具体案例的具体维度对比"

### 差异 4：典型陷阱识别

**baseline**：自己总结了 3 个风险（AI 合规雷区、保健品履约、3 月目标刚性），都是基于 LLM 直觉

**with-skill-v2**：直接引用 24 主题典型陷阱速查表
- **健康/美业类最大陷阱** = 合规风险 → 命中本项目（中医出海属跨主题，但核心归类健康/美业）
- **AI 工具类最大陷阱** = 0 资源启动但需技术能力 + 技术迭代快 3 个月可能失效 → 命中本项目
- **出海/外贸类最大陷阱** = 合规+文化双重风险 → 命中本项目
- **跨主题三大陷阱全中** → with-skill 能识别这是高风险项目

✅ **结论**：with-skill 通过"陷阱表"快速识别本项目踩了多个主题的典型雷区

### 差异 5：可执行建议的具体性

**baseline 立即可做 3 件事**：
1. "把 AI 诊断重新定位为 AI 体质辨识/健康咨询"（通用建议）
2. "找跨境保健品合规律师做 1 小时咨询"（通用建议）
3. "锁定 1 个 MVP 形态"（通用建议）

**with-skill-v2 立即可做 3 件事**：
1. "合规清单 + 当地律师 1 小时咨询（FDA 膳食补充剂注册、加拿大 NHP 备案、AI 诊断免责声明模板三版，预算 1000-3000 美元）" → 引用了"健康/美业类合规陷阱"
2. "MVP 减法：聚焦 YouTube + AI 工具订阅（3 SKU 改 1 SKU）" → 引用了"主题 18 英文工具站单点聚焦"标杆
3. "YouTube 频道主攻 3-5 个场景化中医痛点（失眠/痛经/湿疹/备孕/慢病）" → 引用了"主题 19 ChatGPT 提效场景化策略"标杆

✅ **结论**：with-skill 的每条建议都"有依据"，baseline 是"通用建议"

### 差异 6：评分方法

**baseline**：8 维度算术平均 = (4+3+5+3+3+3+2+3) / 8 = 3.25/5
- 问题：维度权重应该不同（如"法律合规"应该比"团队匹配"权重高）

**with-skill-v2**：6 层加权综合 = 3.75/5
- 权重：本体 0.15 + 可行性 0.20 + 健康度 0.15 + 对比 0.10 + 创新 0.15 + 长期价值 0.25
- 长期价值权重最高 0.25 → 体现"长期主义"
- 可行性权重 0.20 → 体现"能不能做"
- 创新权重 0.15 → 体现"差异化"

✅ **结论**：with-skill 评分更科学，权重反映"商业模式本质"

## 三、with-skill 模式的增量价值

| 价值 | 说明 |
|------|------|
| **知识库对照** | 15 个标杆引用 = 把 skill 知识库变成"诊断的尺子" |
| **方法论固化** | 6 层框架是 skill 内置，不会因 LLM 漂移而变形 |
| **行业语境** | 24 主题典型陷阱 + industry-patterns = 不只看到本项目，还能看到"在行业中算什么水平" |
| **可执行性** | 每条建议都有"参考了哪个标杆"作为依据，可信度 + 可执行度都更高 |
| **评分科学性** | 加权评分比算术平均更合理 |
| **报告专业感** | 客户/投资人看到 with-skill 报告会觉得"这是有方法论的"，baseline 像"个人意见" |

## 四、skill 在多 agent 环境下的注意点

⚠️ **v1 失败原因**：子智能体（agent_name=general）扫描不到 mavis agent 下的 skill 目录

**解决方案**：
- 方案 A：让子智能体用 `Read` 工具显式读 skill 文件（v2 用此方案）
- 方案 B：把 skill 复制到所有 agent 都能看到的公共目录
- 方案 C：子智能体 agent_name 改用 mavis
- 方案 D：Mavis 修复 skill 自动发现机制（多 agent 共享 skill）

推荐**方案 A**（最简单、最稳妥），所有 eval 报告都基于此方案生成。

## 五、最终结论

**business-diagnosis skill 真的有效。** 同一份项目资料：
- 输出量提升 2.8 倍（更详尽）
- 知识库引用从 0 → 15（关键差异）
- 方法论从"自创" → "内置 6 层"（更专业）
- 建议从"通用" → "有标杆依据"（更可信）
- 评分从"算术平均" → "加权"（更科学）

**适用场景**：
- ✅ 复杂项目的系统化诊断（200+ 字资料）
- ✅ 需要横向对比同行标杆的场景
- ✅ 需要给出"可执行、可信、有依据"建议的场景
- ❌ 简单项目的快速评估（杀鸡用牛刀）
- ❌ 客户没准备好资料（先用 15q-self-check.md 问问题）

**最值得用的场景**：客户/创始人给你一份完整项目资料（>500 字），想看一份能拿去融资/给团队/决策的全套诊断报告。
