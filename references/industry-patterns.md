# 行业典型模式库

> 当用户给的资料不充分、或者模式判断困难时，对照这个库找相似案例。

---

## 一、中医出海

### 模式 A：内容+课程
- **价值主张**：教海外华人/外国人学中医
- **客单价**：50-500 美元/课程
- **获客**：YouTube / TikTok / 小红书海外版
- **核心能力**：内容创作 + 中医师资源
- **典型周期**：6-12 个月起步
- **天花板**：年入 100-500 万
- **风险**：内容同质化、转化率低

### 模式 B：保健品/中药出口
- **价值主张**：天然替代/调理
- **客单价**：20-200 美元/单
- **获客**：亚马逊/独立站/海外中医诊所
- **核心能力**：供应链 + 当地合规
- **典型周期**：12-24 个月（含认证）
- **天花板**：年入千万-亿
- **风险**：监管（FDA/各国）严格

### 模式 C：海外中医诊所加盟
- **价值主张**：线下专业服务
- **客单价**：100-500 美元/次
- **获客**：本地化运营 + 华人社群
- **核心能力**：当地医疗执照 + 中医师团队
- **典型周期**：24-36 个月
- **天花板**：年入千万+
- **风险**：重资产、合规复杂

### 模式 D：AI 中医+远程问诊
- **价值主张**：科技赋能传统医学
- **客单价**：50-300 美元/月订阅
- **获客**：技术社区 + 健康 KOL
- **核心能力**：AI 团队 + 中医师 + 合规
- **典型周期**：12-18 个月
- **天花板**：年入 500-5000 万
- **风险**：监管模糊、AI 误诊责任

## 二、AI 咨询/陪跑

### 模式 A：1v1 高客单咨询
- **客单价**：3000-10000 元/单
- **核心能力**：专家 IP + 案例
- **天花板**：年入 100-500 万（个人 IP 上限）

### 模式 B：课程/训练营
- **客单价**：500-5000 元/人
- **核心能力**：内容 + 社群运营
- **天花板**：年入 100-1000 万

### 模式 C：SaaS 工具
- **客单价**：100-1000 元/月订阅
- **核心能力**：技术 + 行业 know-how
- **天花板**：年入 1000 万+（需规模化）

### 模式 D：付费社群
- **客单价**：500-3000 元/年
- **核心能力**：个人 IP + 圈层
- **天花板**：年入 50-500 万
