# 15 题自检清单

> 当用户给的项目信息不充分时（< 200 字或只有想法），用这个清单让用户答。

## 第 1 块：你的项目长啥样（3 题）

**Q1. 你的项目具体是哪种模式？4 选 1**
- A 内容+课程（线上教学，TikTok/YouTube 出海）
- B 保健品/实物出口（亚马逊/独立站卖货）
- C 线下服务/诊所加盟（重资产）
- D 技术驱动/SaaS 化（AI 工具、平台）
- E 其他（你来说）

**Q2. 你的客户是谁？多选**
- 海外华人 / 当地对某主题感兴趣的人 / 行业爱好者 / 跨境创业者
- 其他（你来说）

**Q3. 你的目标市场？多选**
- 东南亚 / 北美 / 欧洲 / 中东 / 港澳台 / 日韩
- 国内 / 其他

## 怎么回我？

**方式 1（一段话）**：按 Q1-Q15 答完
**方式 2（自由发挥）**：把脑子里关于项目的所有想法倒出来
**方式 3（混合）**：答几个确定的 + 把不确定的当问题问
